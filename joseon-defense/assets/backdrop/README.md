# 타이틀 배경 원본

타이틀 화면은 **실물 이미지**를 배경으로 쓴다. 손으로 그린 벡터 지도가 아니라
대동여지도 같은 실제 고지도 스캔을 크게 깔고, 각 방어 기물의 모티브가 된
유물 사진을 흐리게 얹는다.

이 폴더에 원본을 넣고 다음을 실행하면 게임이 쓸 형태로 구워진다.

```
pip install Pillow
python3 tools/bake-backdrop.py
```

결과는 `src/render/backdropAssets.ts` 한 파일이다. **이 폴더의 원본은 커밋하지
않는다** (`.gitignore` 처리) — 구워진 쪽만 커밋한다. 원본은 수십 MB짜리
스캔이고, 저장소에 들어가면 클론이 무거워진다.

이 폴더가 비어 있으면 타이틀은 예전 벡터 지도로 자동으로 돌아간다. 화면이
깨지지는 않지만, 그건 대체품이지 목표가 아니다.

## 필요한 파일

확장자는 `.jpg / .png / .webp / .tif` 아무거나 된다. **이름이 계약이다** —
아래 이름과 정확히 맞아야 해당 자리에 들어간다.

| 파일명 | 무엇 | 어디에 쓰이나 |
| --- | --- | --- |
| `map` | 대동여지도 등 조선 전도 | 배경 전체에 크게 |
| `archer` | 각궁·편전 | 사수 |
| `sword` | 환도·등패 | 살수 |
| `mage` | 승자총통 | 총통 |
| `cannon` | 문종 화차·신기전기화차 | 화차 |
| `frost` | 거마작(拒馬柵) | 거마작 |
| `venom` | 비격진천뢰 | 별파진 |
| `musket` | 조총 | 포수 |
| `banner` | 형명(形名) 기고 | 기고 |
| `scene1`, `scene2`, … | 전투 기록화 (부산진순절도·동래부순절도 등) | 배경에 함께 흩음 |

전부 없어도 된다. 있는 것만 들어가고 없는 자리는 비워둔다. 지도 한 장만
넣어도 배경은 지도로 바뀐다.

## 원본 고르기

- **해상도**: 지도는 긴 변 1600px 이상이면 충분하다. 굽는 쪽에서 어차피
  그 크기로 줄인다. 유물 사진은 340px까지 줄고 흐려지므로 작아도 된다.
- **구도**: 유물은 **한 점만** 크게 찍힌 사진이 좋다. 진열장 전체가 나온
  사진은 340px로 줄면 무엇인지 안 보인다.
- **색**: 신경 쓸 필요 없다. 굽는 쪽에서 전부 먹빛-종이빛 2색조로 통일한다.

## 라이선스

`CREDITS.tsv` 에 출처와 라이선스를 적는다. 탭으로 구분한 세 칸이다.

```
map	김정호 「대동여지도」(1861), 국립중앙박물관 소장	퍼블릭 도메인
musket	○○박물관 소장 조총, 촬영 △△△	CC BY-SA 4.0
```

적어 두면 굽는 쪽이 `BACKDROP_CREDITS` 로 옮겨 실어 준다. 빠진 항목이 있으면
경고가 뜬다.

주의할 점이 하나 있다. **지도 자체가 퍼블릭 도메인인 것과, 그 지도를 찍은
사진이 퍼블릭 도메인인 것은 다른 문제다.** 1861년 목판본은 저작권이 없지만,
박물관이 촬영한 고해상도 스캔에는 별도 이용 조건이 붙어 있는 경우가 있다.
유물 사진은 특히 그렇다 — 유물은 옛것이어도 사진은 최근에 찍힌 것이다.
받기 전에 그 페이지의 이용 조건을 확인한다.
