# 족장 (chieftain)

**내가 어디 서 있느냐가 전투력이다.**

부감으로 지휘하는 RTS인데, 지휘관인 내가 맵 위의 실제 기물이다. 내 주변 반경 안의
부대만 세밀한 명령을 받고, 밖의 부대는 알아서 싸운다. 그래서 두 전선을 동시에
지휘할 수 없다. 그리고 언제든 그 몸으로 **강림**해 1인칭으로 걸어 들어갈 수 있다.
아바타는 죽지 않는다 — 대가는 죽음이 아니라, 내려가 있는 동안 부감을 잃는다는
것이다.

**놀아 보기** → <https://aj-yang.github.io/playground/chieftain/>

```bash
npm install
npm run dev        # http://localhost:5174
npm run build      # tsc --noEmit 먼저 돌고 dist를 굽는다
```

## 조작

| | 부감 | 1인칭 |
| --- | --- | --- |
| 좌클릭 | 부대를 그리로 | 보는 쪽으로 부대를 |
| 우클릭 | 내가 그리로 (**느리다**) | — |
| WASD | 화면을 민다 (놓으면 돌아온다) | 직접 걷는다 (**빠르다**) |
| 1 · 2 · 4 | 방패병 · 도끼병 · 일꾼 생산 | 같음 |
| 3 | 내가 선 자리에 전진 기지 | 같음 |
| Tab | 강림 | 부감으로 |

미니맵(우하단)도 **같은 두 버튼**을 쓴다 — 좌클릭은 부대, 우클릭은 나. 판이
한 화면에 다 안 들어오므로 여기가 판 전체를 보는 눈이다.

느린 이동 명령과 빠른 직접 조종의 **차이가 강림의 유일한 유인**이다. 전선을 급히
옮겨야 할수록 내려갈 이유가 커지고, 자리를 잡으면 올라올 이유가 커진다.

## 지금 상태

**v1 수직 슬라이스.** 노르드 미러 매치 × 피오르드 해안, 상대는 컴퓨터 하나.

땅은 300×180짜리 **한 덩어리**다. 점령·안개·수입은 그 위에 얹은 5×3 지역이
단위이고, 걷는 것은 2.5짜리 통행 격자 위에서 길을 찾는다. 목은 다리가 아니라
파고든 만에서 나온다 — 왜 섬 아홉 개를 버렸는지는 GDD 4.1에 적혀 있다.

검증할 것이 강림 하나뿐이라 나머지는 일부러 안 만들었다 — PvP도, 절차 생성도,
랜덤 이벤트도, 다른 종족·맵도 없다. 이유는 [`docs/GDD.md`](docs/GDD.md) 6장에
적혀 있다.

**합격 기준은 재미있다는 말이 아니라 행동이다.** 규칙 모르는 사람 3명에게 설명 없이
쥐어주고 화면만 본다. 한 번도 강림하지 않거나, 강림 후 끝까지 안 올라오면
불합격이다(GDD 6.5). 판이 끝나면 강림 횟수와 1인칭 체류 비율이 배너에 뜬다 —
나중에 부인할 수 없게 하려고 화면에 남긴다.

## 코드가 어디 있나

| 무엇 | 어디 |
| --- | --- |
| **손잡이 전부** (지휘 반경·아바타 속도·시야·경제) | [`src/data/tuning.ts`](src/data/tuning.ts) |
| 핵심 3규칙 — 지휘 반경·강림·무적 아바타 | [`src/game/Game.ts`](src/game/Game.ts) |
| 땅 — 지역·점령·안개·길찾기 | [`src/game/Board.ts`](src/game/Board.ts) |
| 이어진 맵·해안선·거울상 대칭 | [`src/data/land.ts`](src/data/land.ts) |
| 미니맵 | [`src/ui/Minimap.ts`](src/ui/Minimap.ts) |
| 결정론 수학 (sin·cos·atan2를 직접 짠 이유) | [`src/core/det.ts`](src/core/det.ts) |
| 중립 세 갈래 | [`src/data/neutrals.ts`](src/data/neutrals.ts) |
| 컴퓨터 상대 | [`src/game/Ai.ts`](src/game/Ai.ts) |

수치는 `src/data/` 아래가 단일 진실 공급원이다. `Game`은 **렌더링을 전혀
모른다** — 나중에 결정론적 락스텝으로 PvP를 얹을 때 이 클래스만 두 클라이언트에서
똑같이 돌면 되게 하려는 것이다(GDD 7.2).
